# PingasGPT

**A lightweight, browser-based conversational text generation engine built with JavaScript.**

PingasGPT is a simple experimental AI engine that learns from text, builds word associations, remembers conversations, and generates responses using statistical language patterns.

Unlike traditional AI services, PingasGPT runs entirely in JavaScript without requiring an external AI API. It uses a combination of word association networks, bigram and trigram models, contextual memory retrieval, and probabilistic text generation.

## Features

- **Local text generation** – Generates responses directly in the browser.
- **Automatic learning** – Learns from system prompts, user messages, and its own responses.
- **Word association network** – Builds connections between related words.
- **Contextual memory** – Retrieves previously learned sentences based on relevance.
- **Bigram and trigram generation** – Uses learned word sequences to construct sentences.
- **Conversation history** – Keeps track of recent messages.
- **Custom training** – Teach PingasGPT additional information using text.
- **Network export/import** – Save and restore its learned language model.
- **Configurable settings** – Adjust memory limits, generation length, temperature, and more.
- **No external AI API required** – The engine operates locally after loading its prompt.

## Installation

Include the PingasGPT JavaScript file in your HTML:

```html
<script src="https://pingasgpt.pages.dev/script.js"></script>
```

PingasGPT is exposed globally as:

```js
window.PingasGPT
```

## Getting Started

The engine automatically loads its system prompt when you send your first message.

```js
const response = await PingasGPT.ask("Hello!");

console.log(response);
```

You can also explicitly load the engine:

```js
await PingasGPT.load();
```

The default system prompt is loaded from:

```text
https://pingasgpt.pages.dev/prompt.txt
```

## Configuration

PingasGPT supports a configurable prompt URL.

Set `PingasConfig.prompturl` before loading the engine:

```js
window.PingasConfig = {
    prompturl: "https://example.com/prompt.txt"
};
```

If no custom URL is provided, PingasGPT uses its default prompt.

## API Reference

### `PingasGPT.load()`

Loads the system prompt and trains the engine using its contents.

```js
await PingasGPT.load();
```

Returns the engine instance.

### `PingasGPT.ask(message)`

Sends a message to PingasGPT and returns its generated response.

```js
const response = await PingasGPT.ask("How are you?");
```

Messages and generated responses are automatically learned and added to conversation history.

### `PingasGPT.train(text)`

Trains the engine using additional text.

```js
PingasGPT.train(
    "PingasGPT is an experimental JavaScript text generation engine."
);
```

Returns the engine instance.

### `PingasGPT.retrieve(query, limit)`

Retrieves previously learned sentences that are relevant to a query.

```js
const memories = PingasGPT.retrieve("JavaScript", 5);

console.log(memories);
```

Returns an array of memory entries containing:

- `text` – The learned sentence.
- `source` – Where the sentence originated.
- `time` – Timestamp when it was learned.
- `score` – Relevance score.

### `PingasGPT.getStats()`

Returns information about the current engine.

```js
console.log(PingasGPT.getStats());
```

Example properties:

| Property | Description |
|---|---|
| `name` | Engine name |
| `loaded` | Whether the prompt has loaded |
| `words` | Number of unique words |
| `associations` | Number of word connections |
| `sentences` | Number of retained sentences |
| `memories` | Number of retained memories |
| `conversations` | Number of history entries |
| `promptLength` | Length of the system prompt |

### `PingasGPT.clearMemory()`

Clears learned information and conversation history, then relearns the system prompt if available.

```js
PingasGPT.clearMemory();
```

### `PingasGPT.exportNetwork()`

Exports the current learned network into a JavaScript object.

```js
const backup = PingasGPT.exportNetwork();

const json = JSON.stringify(backup);
```

This includes the prompt, memories, conversation history, word associations, bigrams, and trigrams.

### `PingasGPT.importNetwork(data)`

Restores a previously exported network.

```js
const backup = JSON.parse(json);

PingasGPT.importNetwork(backup);
```

Only networks with the name `PingasGPT` are accepted.

## Training and Learning

PingasGPT learns from three primary sources:

| Source | Description |
|---|---|
| `system` | Sentences from the system prompt |
| `user` | Messages sent by the user |
| `assistant` | Responses generated by PingasGPT |
| `training` | Additional manually supplied training text |

When learning a sentence, PingasGPT:

1. Tokenizes the sentence into words and punctuation.
2. Removes common stop words for association learning.
3. Builds connections between nearby words.
4. Tracks word frequencies.
5. Learns bigram and trigram sequences.
6. Stores the sentence in its memory.

Word associations are weighted according to their distance within a sentence.

## Generation System

PingasGPT combines several techniques to produce responses:

- **Keyword extraction:** Identifies meaningful words in the user's message.
- **Network activation:** Activates related words using learned associations.
- **Memory retrieval:** Searches previously learned sentences for relevant information.
- **Prompt context:** Selects relevant sentences from the system prompt.
- **N-gram generation:** Uses bigram and trigram probabilities to generate additional text.
- **Temperature sampling:** Introduces randomness into word selection.

Trigram generation is preferred, with bigram generation used as a fallback.

## Default Settings

The engine uses the following default configuration:

| Setting | Default | Description |
|---|---:|---|
| `associationWindow` | 4 | Maximum word association distance |
| `minimumAssociation` | 1 | Reserved association threshold setting |
| `learningRate` | 1 | Reserved learning rate setting |
| `maximumMemory` | 500 | Maximum retained memories and sentences |
| `maximumHistory` | 100 | Maximum conversation history entries |
| `maximumSentenceLength` | 45 | Reserved sentence length setting |
| `generationLength` | 55 | Maximum generated tokens |
| `temperature` | 0.8 | Controls generation randomness |

You can modify these settings directly:

```js
PingasGPT.settings.temperature = 0.7;
PingasGPT.settings.generationLength = 80;
PingasGPT.settings.maximumMemory = 1000;
```

## Example Chat Interface

```html
<input id="message" placeholder="Talk to PingasGPT...">
<button onclick="sendMessage()">Send</button>

<div id="response"></div>

<script>
async function sendMessage() {
    const input = document.getElementById("message");
    const output = document.getElementById("response");

    const response = await PingasGPT.ask(input.value);

    output.textContent = response;
    input.value = "";
}
</script>
```

## Important Notes

- PingasGPT is an experimental statistical text generation engine, not a large language model.
- It does not use neural networks or transformer architecture.
- Its responses are generated from learned word sequences and associations.
- Generated responses may be repetitive, grammatically incorrect, or unrelated to the question.
- Conversation memory is held in JavaScript memory and is not automatically persisted across page reloads.
- Export your network if you want to preserve learned information.
- The system prompt must be accessible through `fetch()`.
